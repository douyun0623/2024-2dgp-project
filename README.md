# Soul Knight 모작 2D 액션 슈팅 게임

Python과 Pico2D로 제작한 탑다운 액션 슈팅 게임입니다.  
고정된 던전 맵의 전투 구역을 차례로 돌파한 뒤 포탈을 통해 보스 맵으로 이동합니다.

> Python · Pico2D · Tiled Map

## 프로젝트 소개

플레이어는 5개의 전투 구역을 통과한 뒤 블랙 드래곤 보스와 전투합니다.

각 전투 구역에 처음 들어가면 정해진 수의 적이 생성되고 출구가 잠깁니다. 구역 안의 적을 모두 처치하면 출구가 다시 열리며, 마지막 포탈에 도달하면 별도의 보스 맵으로 전환됩니다.

맵 구조는 Tiled로 제작한 고정 맵입니다. 던전 지형이 절차적으로 생성되는 방식은 아니며, 전투 구역마다 적의 종류와 생성 위치가 무작위로 결정됩니다.

## 구현 범위

수업에서 제공된 `gfw` 프레임워크를 기반으로 다음 게임플레이 코드를 구현했습니다.

- 플레이어 이동, 구르기, 체력과 쿨타임 UI
- 전투 구역 상태와 출구 잠금 처리
- 무기 5종, 투사체, 자동 조준과 충돌 판정
- 일반 적 3종과 보스의 추적·공격·피격·사망 처리
- 일반 맵에서 보스 맵으로의 전환
- 게임 오버 및 게임 클리어 화면

## 주요 시스템

### 전투 구역 진행

전투 구역은 `Entering`, `Active`, `Complete` 상태로 관리합니다.

- 총 5개 구역에 각각 3, 4, 4, 5, 5마리의 적 생성
- 구역 진입 시 적 종류와 생성 위치 결정
- 전투 시작 시 출구 타일을 충돌 대상으로 추가
- 적이 모두 제거되면 출구 충돌을 해제
- 마지막 포탈에서 기존 맵을 제거하고 보스 맵과 보스 생성

구역 상태와 타일 충돌 설정을 함께 변경해 전투가 끝나기 전에는 다음 구역으로 이동할 수 없도록 구성했습니다.

### 플레이어와 구르기

- WASD 기반 8방향 이동
- 좌우 이동 방향에 따른 스프라이트 반전
- 구르기 중 이동 속도 증가와 무적 판정
- 1초 구르기 쿨타임
- 플레이어 체력과 구르기 쿨타임 게이지
- 월드 좌표를 화면 좌표로 변환하는 카메라 추적

### 무기와 투사체

| 무기 | 공격력 | 투사체 속도 | 쿨타임 | 특징 |
| --- | ---: | ---: | ---: | --- |
| AK-47 | 30 | 400 | 0.3초 | 기본 연사 무기 |
| Bazooka | 50 | 200 | 1.0초 | 명중 지점 주변에 범위 피해 |
| MP5 | 15 | 400 | 0.2초 | 빠른 연사 |
| Revolver | 45 | 400 | 0.7초 | 높은 단발 피해 |
| Glock | 10 | 300 | 0.2초 | 짧은 쿨타임 |

발사 시 살아 있는 적 중 가장 가까운 대상을 찾아 투사체 방향을 계산합니다. 투사체는 무기 생성 시 미리 준비하며, 화면 밖으로 나가거나 적에게 명중하면 비활성화한 뒤 다시 사용합니다.

투사체와 적의 충돌은 바운딩 박스를 이용해 검사합니다.

### 적 AI와 보스전

일반 적은 늑대, 나이트 윙, 오크 3종이며 보스는 블랙 드래곤입니다.

- 플레이어와의 거리에 따라 대기, 추적, 공격 전환
- 피격 후 5초 동안 추적 상태 유지
- 피격 시 짧은 경직과 밀려나는 처리
- 공격 애니메이션의 마지막 프레임에서 사거리 재확인 후 피해 적용
- 사망 애니메이션 처리 후 월드에서 제거
- 적과 보스의 체력 게이지 표시

보스는 두 가지 공격 애니메이션 중 하나를 선택합니다. 보스전에서는 보스를 포함한 적 수가 6마리 미만이면 일반 적이 추가로 생성되며, 보스가 제거되면 게임 클리어 화면으로 전환됩니다.

## 코드 구성

| 파일 | 역할 |
| --- | --- |
| `main_scene.py` | 월드 레이어 구성, 맵 로드, 투사체 충돌 검사 |
| `player.py` | 플레이어 조작, 구르기, UI, 전투 구역과 맵 전환 |
| `weapon.py` | 무기 5종, 투사체 이동, 자동 조준, 범위 피해 |
| `enemy.py` | 적 데이터, AI 상태, 일반 적과 보스 생성 |
| `game_over_scene.py` | 게임 오버 화면 |
| `game_end_scene.py` | 게임 클리어 화면 |
| `gfw/` | 수업에서 제공된 게임 프레임워크 |
| `res/` | 스프라이트, 폰트, Tiled 맵 리소스 |

## 조작법

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| `J` | 구르기 |
| `K` | 공격 |
| `L` | 무기 교체 |
| `Esc` | 종료 |

## 실행 방법

Pico2D가 준비된 Python 환경에서 저장소 루트의 `main_scene.py`를 실행합니다.

```bash
python main_scene.py
```
