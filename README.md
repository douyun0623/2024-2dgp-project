# Soul Knight 모작 2D 액션 게임

Python과 Pico2D로 제작한 탑다운 액션 슈팅 게임입니다.  
고정된 던전 맵의 전투 구역을 차례로 돌파한 뒤, 포탈을 통해 보스 맵으로 이동하는 흐름으로 구성했습니다.

수업용 `gfw` 프레임워크를 기반으로 플레이어 상태, 전투 구역 진행, 무기와 투사체, 적 AI, 충돌 처리 등을 구현했습니다.

> 2024년 2학기 개인 프로젝트  
> Python · Pico2D · Tiled Map Editor

## 게임 진행

플레이어는 맵을 탐색하며 5개의 전투 구역을 통과합니다.

전투 구역에 들어가면 적이 생성되고 출구가 잠깁니다. 구역 안의 적을 모두 처치하면 출구가 다시 열리며, 마지막 포탈에 도달하면 보스 맵으로 전환됩니다. 보스 맵에서는 블랙 드래곤과 추가로 생성되는 일반 적을 상대합니다.

## 주요 구현

### 플레이어 상태와 구르기

플레이어의 동작을 `Idle`, `Running`, `Rolling`, `Hurt` 상태로 나누어 관리했습니다.

- WASD 이동과 진행 방향에 따른 스프라이트 반전
- 구르기 중 이동 속도 증가와 무적 판정
- 구르기 쿨타임 적용
- 체력과 구르기 쿨타임을 표시하는 UI 게이지
- 맵 좌표와 화면 좌표를 분리한 카메라 추적

### 전투 구역 관리

각 전투 구역은 `Entering`, `Active`, `Complete`, `Portal` 상태를 가집니다.

- 구역 최초 진입 시 범위 안에 적 생성
- 전투 중 출구 타일의 충돌 활성화
- 적을 모두 처치하면 충돌을 해제하고 다음 구역 개방
- 마지막 포탈 진입 시 기존 맵을 제거하고 보스 맵으로 전환

구역 진행과 맵 충돌을 함께 관리해 플레이어가 전투를 건너뛰지 못하도록 구성했습니다.

### 무기와 투사체

AK-47, 바주카, MP5, 리볼버, 글록 총 5종의 무기를 구현했습니다.

각 무기는 공격력, 투사체 속도, 쿨타임, 보유 투사체 수가 다릅니다. 발사 시 살아 있는 적 중 가장 가까운 대상을 찾아 투사체 방향을 계산하며, 바주카는 명중 지점 주변의 적에게 추가 피해를 줍니다.

투사체는 발사할 때마다 새로 만들지 않고 무기 생성 시 미리 준비한 뒤, 사용 가능 상태를 전환하며 재사용하도록 구성했습니다.

### 적 AI와 보스

일반 적 3종과 보스 1종을 구현했습니다.

- 대기, 추적, 공격, 피격, 사망 상태
- 플레이어와의 거리에 따른 추적과 공격 전환
- 피격 후 일정 시간 동안 플레이어를 적극적으로 추적
- 공격 애니메이션의 마지막 프레임에서 사거리를 다시 확인한 뒤 피해 적용
- 사망 애니메이션이 끝난 뒤 오브젝트 제거
- 보스전 중 일반 적 추가 생성

## 구현 과정에서 해결한 문제

### 전투 도중 구역을 빠져나가는 문제

처음에는 적만 생성했기 때문에 플레이어가 전투를 무시하고 다음 구역으로 이동할 수 있었습니다. 전투 구역의 상태와 타일 충돌 값을 함께 관리해, 전투가 시작되면 출구를 막고 적이 모두 제거된 뒤에만 다시 열리도록 수정했습니다.

### 공격 판정과 애니메이션이 어긋나는 문제

거리 조건을 만족하는 즉시 피해를 주면 공격 모션보다 먼저 플레이어가 맞는 문제가 있었습니다. 공격 애니메이션의 마지막 프레임에서 사거리를 다시 검사하고 피해를 적용해 시각적인 타이밍과 실제 판정을 맞췄습니다.

### 반복적으로 생성되는 투사체 관리

공격할 때마다 투사체 객체를 생성하는 대신 무기별로 사용할 투사체를 미리 준비했습니다. 화면 밖으로 나가거나 적에게 명중한 투사체는 비활성화한 뒤 다음 발사 때 다시 사용합니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| `J` | 구르기 |
| `K` | 공격 |
| `L` | 무기 교체 |
| `Esc` | 게임 종료 |

## 프로젝트 구조

```text
2024-2dgp-project/
├─ main_scene.py        # 메인 월드 구성과 충돌 검사
├─ player.py            # 플레이어 상태, 이동, 구르기, 전투 구역 관리
├─ weapon.py            # 무기 5종과 투사체 처리
├─ enemy.py             # 적 AI, 데이터, 일반 적과 보스 생성
├─ game_over_scene.py   # 게임 오버 화면
├─ game_end_scene.py    # 게임 클리어 화면
├─ gfw/                 # 수업용 게임 프레임워크
└─ res/                 # 이미지, 맵, 폰트 리소스
```

## 실행 방법

Pico2D가 설치된 Python 환경에서 저장소의 루트 디렉터리로 이동한 뒤 실행합니다.

```bash
python main_scene.py
```
